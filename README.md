# Molargik Software Website

This repository contains the source code for **[molargiksoftware.com](https://molargiksoftware.com)** — the official portfolio and project showcase of **Nicholas Molargik**, founder of Molargik Software LLC.  
Built with **React**, **TypeScript**, and **Vite**, the site highlights featured apps, company values, and contact information in a modern, performant single-page design.

---

## 🧱 Tech Stack

- ⚛️ **React + TypeScript** — component-driven UI with strict type safety  
- ⚡ **Vite** — lightning-fast dev server & optimized build output  
- 🎨 **Tailwind CSS** — responsive styling and theme consistency  
- 🧭 **React Router** — client-side navigation between pages  
- 🧩 **ESLint + TypeScript ESLint** — robust linting and type-aware static analysis  
- ☁️ **Nginx + Raspberry Pi Server** — self-hosted deployment (reverse-proxied via Cloudflare)
